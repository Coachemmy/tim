## 📖 Description

Official website for **Total Invasion Ministries**, a Christ-centered community based in Malawi dedicated to spreading the Gospel, nurturing believers, and making a difference locally and globally. This React-based platform provides information about our mission, values, leadership, and easy ways for visitors to connect with us.

## ✨ Features

- **About Page**: Mission, vision, core values, ministry statistics, and leadership profiles
- **Contact Page**: Validated contact form, location details, service times, and social media links
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices
- **Modern UI**: Clean, accessible interface built with Tailwind CSS and lucide-react icons
- **Form Validation**: Client-side validation with success feedback and error handling
- **Smooth Animations**: Hover effects and transitions for enhanced user experience

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/total-invasion-ministries.git

# Navigate to project directory
cd total-invasion-ministries

# Install dependencies
npm install

# Start development server
npm run dev


## 💻 Usage
# Development mode
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint code
npm run lint
